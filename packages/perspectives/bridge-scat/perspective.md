# Scat on the bridges

A bridge that is hummed aloud is scatted instead: the same notes, to the same rhythm, but each note a percussive syllable, drawn from one set in `prompts.json` for the whole Song, never the same syllable twice in a row. Every voice humming the bridge sings the same syllables. The guide the Music grows from is still hummed, as always; whether a bridge is heard at all is still the bridge singers' to say.
