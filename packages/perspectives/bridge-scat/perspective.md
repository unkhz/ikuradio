# Scat on the bridges

A bridge that is hummed aloud is scatted instead: the same notes, to the same rhythm, but each note a lively IPA syllable drawn from one palette in `prompts.json` for the whole Song — trills, lateral fricatives, uvulars, glottal pops, affricates, and rounded vowels — phrased to the melody's pitch contour and rhythm without repeating twice in a row. Every voice humming the bridge sings the same IPA syllables directly through Chimera. The guide the Music grows from is still hummed, as always; whether a bridge is heard at all is still the bridge singers' to say.
