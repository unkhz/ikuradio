# Arrangement

Which parts a Song is made of, in what order, with the parameters each is given.

A JSON declaration of instances in order, bridges included, checked by a schema made from the parts. Instances with one name sing the same words. This is where the Composer edits.

Its page draws the Arrangement as a session is drawn: regions along a ruler in seconds, with bars where there is a tempo and free time drawn as free; a lane for each Track, its Blocks coloured by key so a sound placed again is seen as the same, overlaps stacked, fades drawn as ramps; and a line wherever the words turn over. Where a lane makes nothing yet it says so. Every position is the server's, from `resolve`.
